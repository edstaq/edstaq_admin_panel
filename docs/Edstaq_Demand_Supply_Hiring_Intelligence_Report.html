3. The 4-Pillar Hiring Requirement Profile & Mathematical Model

As specified by Edstaq academic management, teacher recruitment must be qualified across four core parameters:

  • 1. Target Subject: Mathematics, English, Hindi, Basic Science, Physics, Chemistry, Accountancy.
  • 2. Division / Stage: Lower Primary (LP: 1-4), Upper Primary (UP: 5-7), High School (HS: 8-10), Higher Secondary (HSS: +1/+2).
  • 3. Curriculum / Board: Kerala State Syllabus vs. CBSE Syllabus (or Dual-Board competency).
  • 4. Teaching Language / Medium: English Medium, Malayalam Medium, or Bilingual / Mixed Delivery.

3.1 Mathematical Engine

H_required = max(0, ceil((Demand_hours - Supply_hours) / Standard_Capacity_per_Teacher))
If Demand >= 2 and Current_Active_Teachers = 0: H_required = max(1, ceil(Demand * 0.5))

3.2 Dynamic Reserve / Buffer Pool (B_reserve)

To absorb future trend spikes once Supply = Demand, a reserve buffer is maintained by level:

  • Higher Secondary (+1/+2): 50% buffer (High conversion value ~75%)
  • High School (Classes 8-10): 40% buffer (Board exam volume)
  • Upper Primary (Classes 5-7): 30% buffer
  • Lower Primary (Classes 1-4): 25% buffer

4. The 'Phantom Supply' Dilemma & Cluster-Based Anti-Cannibalization

The Maneesha Case Study: Understanding Shared Resource Strain

Consider teacher Maneesha on the roster:
• Maneesha is qualified to teach Mathematics for Classes 5 to 10 (6 classes).
• She teaches both Kerala Syllabus and CBSE Syllabus (6 × 2 = 12 total subject combinations).
• However, Maneesha has only 3 sessions of available time per week.

If one student books Maneesha for 3 sessions/week in Class 10 CBSE Maths, Maneesha's capacity immediately drops to ZERO. Consequently, all other 11 combinations instantly lose their teacher supply!

A naive system that looks at each subject individually creates a false sense of security (Phantom Supply). In reality, 1 teacher with 3 sessions can only service 1 student.

Session-Weighted Cluster Pooling Solution

  • Nominal Headcount vs True Available Session Capacity: Distinguishing on-paper qualification from actual unbooked time slots in peak student hours (17:00-22:00).
  • Cross-Subject Cannibalization Factor (κ): κ = Total_Qualified_Combinations / Available_Weekly_Sessions. When κ > 1.5, the resource is flagged as 'Hyper-Shared / High Strain'.
  • Competency Cluster Aggregation: Instead of calculating Class 5, 6, 7 in silos, demand and supply are pooled by domain (e.g., 'High School Mathematics Cluster'). Hiring targets recommend versatile teachers capable of covering the cluster pool.
  • UI Strain Indicators: Subject rows display a '⚠️ Shared Capacity (Stretched across N subjects)' badge to alert academic coordinators.
